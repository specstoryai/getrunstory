# Changelog

What changed in RunStory that you will notice. The newest entries are first.

`runstory update` updates the command line on your machine. `runstory help changes` lists each command that was renamed and what to type now.

## November 2026

- **RunStory is in beta, and anyone can create an account**, with GitHub or an email address. Your first 10 checks are free.
- **Gemini 4 Neon is Google's default model in a check**, since 19 November. It replaced Gemini 4 Carbon, which a check can still name.
- **This repository opened.** It holds RunStory's guides, the page your agent reads during setup, and the issue tracker.
